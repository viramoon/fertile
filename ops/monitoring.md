# 监控与验证记录

| 指标 | 记录方式与用途 |
| --- | --- |
| 断线时间 / 次数 | 按连接、协议、进程、profile、错误类型记录起止与重试，区分静默超时和明确关闭 |
| 恢复耗时 | 分重连、认证、重订阅、补数、对账和业务 ready，不能用重连成功时间代替 |
| 行情延迟 / 数据年龄 | 源事件时间、接收时间、最新有效时间与阈值；按标的和数据源分类 |
| 订单状态可信度 | 未决写请求、对账差异、重复防护和暂停 / 恢复事件 |
| 错误类型 | 网络、认证、限流、地区拒绝、数据、数据库、产物和 Tunnel，避免全部归为网络 |
| 源 IP | 仅在服务端可见时记录，不从查 IP 网站结果推断实际交易连接源地址 |
| 公网可达性 | 本地 live / ready 与公网域名内容探测并列，记录 502 / 530 和版本不匹配 |
| 持久化与恢复 | catalog 水位、备份时间、恢复演练、磁盘和重建阶段 |

日志 / 指标包含 fertile tag、组件 commit、profile、运行模式、脱敏关联 ID 与时间；禁止记录密钥或完整账户信息。TBD：采集工具、指标格式、保留期、告警阈值及负责人。

按 ADR 进行覆盖交易时段的 24～72 小时真实协议观察，并注入断网、认证失效、进程和云电脑重启；当前仅设计，未执行连续测试。短期 QUIC 测试和 15～30 秒恢复目标不是长期可用性保证。
